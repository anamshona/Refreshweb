Catatan penggunaan

Di halaman ini: halaman target tampil di kotak pratinjau. Sebagian situs (bank, media sosial, Google, dan lainnya) menolak ditampilkan di dalam halaman lain. Jika kotak tetap kosong atau muncul pesan penolakan, pakai Jendela terpisah.

Jendela terpisah: membuka halaman di jendela baru dan memuat ulangnya sesuai jeda. Izinkan pop-up untuk alamat ini, lalu biarkan jendela tetap terbuka.

Tetap berjalan: biarkan tab ini terbuka. Pengaturan tersimpan di peramban, dan hitungan memakai waktu nyata sehingga tetap akurat walau tab di latar belakang.

Dipakai di mana saja: ini satu file HTML tanpa server. Simpan, lalu buka di peramban perangkat apa pun, atau unggah ke hosting statis seperti GitHub Pages atau Netlify. Alamat http:// tidak bisa ditampilkan di halaman https://; pakai Jendela terpisah untuk kasus itu.
